# Research and differentiation

Sources reviewed November 1, 2026:
- EventsAir Planner Assistant launch: https://www.eventsair.com/blog/planner-assistant-launch — existing natural-language event insights and platform actions; establishes overlap, not novelty.
- WedPlan: https://www.weddingplanning.in/ — Indian wedding coordination, guest logistics, budget data and AI questions; establishes competition.
- Planning Pod Barber Museum case study (historical vendor-published testimonial): https://planningpod.com/blog/museum-event-management-software-barber-vintage-motorsports-museum-case-study — reports 32+ hours/month saved by centralising workflows. This is neither independently audited nor a result for UtsavOps.

Candidate differentiation: an explicit change → deterministic impact → human review → operational update → confirmation-task workflow for celebrations. No exhaustive competitor audit or superiority claim is made.

Validation plan: compare time and omissions on identical guest-count and delay scenarios using an organiser's existing method and this app. Collect actual organiser feedback on clarity and workload. Profit or satisfaction improvement requires real pilot evidence. No customer study has been conducted for this prototype.
